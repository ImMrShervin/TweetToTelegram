# TweetToTelegram

یه ربات تلگرام برای گرفتن اسکرین شات از توییت و ارسال اون به کانال

کافیه لینک توییت رو برای ربات بفرستید تا اطلاعات توییت رو دریافت کنه و ازش یه اسکرین شات بسازه

میتونید برای هر کانال لوگوی جداگانه تنظیم کنید تا لوگو روی تصویر واترمارک بشه و در نهایت تصویر همراه با کپشن به کانال ارسال بشه

## امکانات

* گرفتن اسکرین شات از توییت شامل متن عکس و ویدیو
* ارسال لینک ویدیو به صورت جداگانه
* امکان اضافه کردن چند کانال برای هر ادمین
* تنظیم لوگوی اختصاصی برای هر کانال
* تنظیم موقعیت اندازه و شفافیت واترمارک
* امکان تغییر ایموجی تیتر و پاراگراف کپشن
* تغییر اندازه و رنگ فونت
* تغییر رنگ پس زمینه کارت و پس زمینه کلی
* امکان قرار دادن تصویر پس زمینه از طریق لینک
* مخفی کردن تعداد لایک ریتوییت و کامنت
* حذف تیک تایید
* مخفی کردن توییت نقل قول شده
* حذف تاریخ و زمان
* مخفی کردن عکس یا ویدیو
* حذف سایه
* تنظیم فاصله از حاشیه
* تنظیم عرض نهایی تصویر
* مدیریت ادمین ها
* تنظیمات جداگانه برای هر ادمین
* دریافت اطلاعات توییت از طریق وب سرویس های fxtwitter و vxtwitter

## ساختار پروژه

| فایل           | توضیحات                                                            |
| -------------- | ------------------------------------------------------------------ |
| `bot.py`       | هندلرها منوها و جریان اصلی ربات                                    |
| `renderer.py`  | ساخت کارت HTML گرفتن اسکرین شات با Chromium واترمارک و ساخت کپشن   |
| `tweet.py`     | دریافت اطلاعات توییت از وب سرویس                                   |
| `db.py`        | مدیریت دیتابیس SQLite و ذخیره کانال ها تنظیمات ادمین ها و وضعیت ها |
| `keyboards.py` | کیبوردها و منوهای اینلاین                                          |
| `config.py`    | تنظیمات پیش فرض و خواندن فایل `.env`                               |

## راه اندازی

اول پیش نیازها رو نصب کنید

```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
playwright install chromium
playwright install-deps chromium
```

بعد فایل `.env` رو بسازید

```bash
cp .env.example .env
```

داخل فایل `.env` توکن ربات و آیدی ادمین ها رو وارد کنید

```env
BOT_TOKEN=your_bot_token
ADMINS=123456789
```

برای اجرای ربات

```bash
python bot.py
```

## اجرای دائم روی سرور

اگر میخواید ربات روی سرور همیشه در حال اجرا باشه میتونید از systemd استفاده کنید

```ini
[Unit]
Description=TweetToTelegram Bot
After=network.target

[Service]
WorkingDirectory=/root/tweetshot_bot
ExecStart=/root/tweetshot_bot/venv/bin/python bot.py
Restart=always

[Install]
WantedBy=multi-user.target
```
