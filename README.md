# ☑️ ربات اسکرین‌شات از توییت و ارسال به کانال

لینک توییت را به ربات می‌دهید → ربات از توییت اسکرین‌شات حرفه‌ای می‌سازد، لوگوی کانال انتخابی را روی آن واترمارک می‌کند و با کپشن به کانال ارسال می‌کند.

## 🔻 امکانات
- اسکرین‌شات از لینک توییت شامل متن، تصویر و ویدیو (لینک ویدیو جداگانه ارسال می‌شود)
- مدیریت کانال‌ها برای هر ادمین به صورت جداگانه، هر کانال با لوگوی اختصاصی
- واترمارک لوگوی کانال (موقعیت، اندازه و شفافیت قابل تنطیم)
- تعیین ایموجی تیتر و پاراگراف کپشن پست
- تغییر اندازه فونت، رنگ فونت، رنگ پس‌زمینه کارت و رنگ پس‌زمینه کلی
- تصویر پس‌زمینه به صورت لینک
- مخفی کردن آمار (لایک/ریتوییت/کامنت)، حذف تیک تأیید، مخفی کردن توییت نقل‌قول، حذف تاریخ و زمان، مخفی کردن عکس/ویدیو، حذف سایه
- تغییر فاصله از حاشیه و عرض نهایی تصویر
- مخصوص ادمین + مدیریت اکانت ادمین‌ها
- متصل به وب‌سرویس (fxtwitter / vxtwitter) برای دریافت داده‌های توییت

## 📂 ساختار فایل‌ها
| فایل | کاربرد |
|---|---|
| `bot.py` | هندلرها، منوها و جریان کار ربات |
| `renderer.py` | ساخت HTML کارت، اسکرین‌شات با Chromium، واترمارک لوگو، ساخت کپشن |
| `tweet.py` | دریافت اطلاعات توییت از وب‌سرویس |
| `db.py` | دیتابیس SQLite (کانال‌ها، تنظیمات، ادمین‌ها، وضعیت‌ها) |
| `keyboards.py` | کیبوردها و منوهای اینلاین |
| `config.py` | تنطیمات پیش‌فرض و خواندن .env |

## 🚀 راه‌اندازی
```bash
# 1) نصب پیش‌نیازها
python3 -m venv venv && source venv/bin/activate
pip install -r requirements.txt
playwright install chromium

# 2) تنطیم توکن و ادمین
cp .env.example .env
nano .env      # BOT_TOKEN و ADMINS را پر کنید

# 3) اجرا
python bot.py
```

برای اجرای دائم روی سرور (systemd):
```ini
[Unit]
Description=TweetShot Telegram Bot
After=network.target

[Service]
WorkingDirectory=/root/tweetshot_bot
ExecStart=/root/tweetshot_bot/venv/bin/python bot.py
Restart=always

[Install]
WantedBy=multi-user.target
```

## 🧭 روش استفاده
1. `/start` → منوی اصلی
2. **➕ افزودن کانال** → آیدی کانال (ربات باید ادمین کانال باشد) → ارسال لوگو
3. **🕊 ارسال توییت** → لینک توییت → پیش‌نمایش → کپشن (خط اول = تیتر) → انتخاب کانال → ـ**تایید و ارسال**
4. **⚙️ تنطیمات** → تغییر فونت، رنگ‌ها، مخفی‌سازی اجزا، ایموجی‌ها و واترمارک
5. **👑 مدیریت اکانت** → افزودن/حذف ادمین (فقط مالک ربات)

## ⚠️ نکات
- هر ادمین کانال‌ها و تنطیمات مستقل خود را دارد.
- ویدیوی توییت در اسکرین‌شات به صورت فریم اول با آیکون پخش نمایش داده می‌شود و لینک ویدیو جداگانه ارسال می‌شود.
- برای فونت فارسی بهتر، فونت Vazirmatn را روی سرور نصب کنید.
